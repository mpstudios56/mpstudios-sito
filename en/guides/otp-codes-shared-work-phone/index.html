OTP codes on a shared work SIM: how to get them to the right colleague

by Marcello Pandolfo · Updated 21 November 2026

If one office phone receives the one-time login codes for shared business portals, the quickest way to get each code to the colleague waiting for it is automatic forwarding with rules per sender, plus a booking that says who is logging in right now.

The problem

  • Many business services (carrier portals, supplier dashboards, online banking) send the code to a single phone number.
  • That number often sits on a work SIM in a drawer or on one person's desk.
  • Whoever is logging in has to ask for the code, which may expire in the meantime.

Manual workarounds and their limits

  • Asking whoever holds the phone only works if that person is there and free.
  • Sending a screenshot in a chat leaves the code in the chat history.
  • Leaving the phone unlocked in a shared spot means anyone can use it and nobody knows who read what.

What automation needs

  • A rule per sender: «messages from portal X go to Mario and Laura».
  • A way to say who is logging in now, so the code reaches only them.
  • A log of what was forwarded, to whom and when.
  • No outside server in between, because codes are confidential.

How Batonkey does it

  • The work phone (Host) reads notifications and applies your rules.
  • Colleagues install the free Guest app and pair with a single-use QR code valid for 24 hours.
  • Whoever needs to log in taps the provider: for 5 adjustable minutes, that provider's next message goes only to them.
  • Email and SMS go out automatically; WhatsApp and Telegram with one tap. Every send is logged.
