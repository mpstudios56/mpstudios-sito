Applications › Guide numérique de la location de vacances

Benarri

En développement

Benarri est un guide numérique pour les voyageurs d'une location de vacances : Wi-Fi, clés, règles, stationnement, contacts, bus et urgences en cinq langues. Il remplace le classeur papier et les longs messages WhatsApp.

Benarri

Gratuit pour les voyageurs

Benarri Host

Payant pour les loueurs

Captures d'écran

Benarri Host, pour les loueurs

  • Un guide par logement, avec son logo et ses couleurs.
  • Traduction d'un geste en anglais, allemand, français et espagnol, faite sur le téléphone.
  • Publication par un lien ou un QR ; séjours avec les dates tirées du calendrier Airbnb ou Booking.
  • Messages aux voyageurs avec accusé de lecture et acceptation du règlement intérieur.

Benarri, pour les voyageurs

  • Le guide dans la langue du voyageur, lisible hors connexion.
  • Wi-Fi avec QR, contacts avec appel, WhatsApp et carte, horaires des bus, numéros d'urgence.
  • Qui ne veut pas installer l'application ouvre le même guide dans le navigateur.

Où sont les données

  • Dans le Google Drive du loueur, dans un dossier dédié. Aucun serveur du développeur.
  • Les voyageurs ne créent pas de compte et ne s'inscrivent pas.

Questions fréquentes

Les voyageurs doivent-ils installer une application ?

Non. Le guide s'ouvre aussi dans le navigateur depuis le lien partagé ; avec l'application Benarri, il se lit même hors connexion.

Dans quelles langues est le guide ?

Italien, anglais, allemand, français et espagnol. La traduction se fait sur le téléphone du loueur et elle est gratuite.

Où sont enregistrées les données ?

Dans le Google Drive du loueur, dans un dossier Benarri. Il n'y a pas de serveur du développeur.

Fonctionne-t-il avec Airbnb et Booking ?

Benarri Host lit le calendrier des réservations (iCal) pour créer les séjours aux bonnes dates.

Historique des versions

Aucune version publique pour le moment : l'application est en développement.
