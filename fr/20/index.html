Comment fonctionne la numérotation

  • Une série compte vingt visuels, chacun avec un numéro fixe : le loup est 7/20¹, le lion 19/20¹.
  • Le numéro est imprimé sur le vêtement, à côté de la signature MPStudios.
  • Quand la série 20¹ sera close, la série 20² sortira avec vingt nouveaux visuels. Les séries closes restent ci-dessous, dans l'archive.
